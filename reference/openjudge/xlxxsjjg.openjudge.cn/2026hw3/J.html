描述

猫尾草同学迷上了离散数学中的逻辑运算，但他算的头都晕了，也没算出个所以然。他只好找到你，让擅长编程的你帮他解决这个问题。

输入
一个由一行字符串表达的布尔运算式，只包含 or、and、not、true、false 和空格，不同的运算符或true、false之间至少有一个空格隔开。运算符优先级从低到高依次为 or、and、not，优先级高的运算符先计算，相同优先级的运算符从左到右运算，不涉及括号。
输出
输出一行表示运算结果：true 或者 false，如果逻辑式有误（不合法）则输出 error。
样例输入
true or false and false
样例输出
true
提示
对于全部数据，保证输入数据串长小于 256
