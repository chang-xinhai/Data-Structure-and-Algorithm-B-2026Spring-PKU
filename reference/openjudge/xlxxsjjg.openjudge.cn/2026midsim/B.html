B:喝喝喝

描述

你面前有 n 瓶可乐，从左到右依次编号为 1∼n，瓶子可能是空的也可能装着可乐。

你每次可以选择一对 l,r(l≤r)，然后把 l∼r 号瓶子中的所有可乐拿起来全部喝完。你想一次把桌上剩的可乐全喝完，请问你最少要拿起几个瓶子？

你有可能一个瓶子都不需要拿起来。

输入
第一行一个整数 n。

第二行 n 个整数，第 i 个整数为 1 表示第 i 个瓶子装着可乐，为 0 表示第 i 个瓶子是空的。
输出
一行一个整数 k，表示最少拿起的瓶子数。
样例输入
6
0 0 1 1 0 1
样例输出
4
提示
【样例解释】
想要一次喝完可乐，则最优选择为l=3，r=6，然后把3~6号共4个瓶子拿起来喝完。
【数据范围】
0 < n < 1e5
