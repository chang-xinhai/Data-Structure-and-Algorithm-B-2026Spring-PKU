5. 并查集

  • 维护连通块 / 等价类；不能回答路径细节。
  • 食物链类：维护“到根的关系/距离”，普通并查集不够。
fa = list(range(n+1))
def find(x):
    while fa[x] != x:
        fa[x] = fa[fa[x]]
        x = fa[x]
    return x
def union(a,b):
    ra, rb = find(a), find(b)
    if ra != rb: fa[ra] = rb

6. 字符串

  • 基础：split/join、反转、计数、排序。
  • KMP：模式串、周期、前后缀重叠、所有出现位置。
  • 整体平移匹配：转相邻差分；哈希可快比子串但有冲突。
def pi(s):
    p=[0]*len(s)
    for i in range(1,len(s)):
        j=p[i-1]
        while j and s[i]!=s[j]: j=p[j-1]
        if s[i]==s[j]: j+=1
        p[i]=j
    return p

9. 考场 Checklist

  • 先扫全卷：A/B 稳拿，难题先写模型不死磕。

10. 题型 → 模板速配

多行句子 / EOF按行读；不要把所有词混成 token 流。 最小区间 / 总费用线性扫描；写单项贡献或维护首尾。 括号 / 表达式 / D++栈模拟 + 额外状态：作用域、错误标记、当前复杂度。 层 / 最短步数 / 扩散BFS；队列元素放完整状态；入队即标记。 排名确定 / 先后可推建有向图 + 传递闭包；与所有人关系可判才确定。 最小连接代价Kruskal 或 Prim；先判断图是否连通。 选或不选 / 容量背包；01 倒序、完全正序。 子树保留若干资源树形 DP / 树形背包，孩子逐个合并。

11. 关键算法选择表 + Python 小件

堆 / Huffmanheapq 维护最小值；Huffman 每次合并两个最小权。 BST / AVL核心是有序性；AVL 多考概念与旋转，不一定手写完整树。 Prim vs Kruskal稠密图可 Prim；边表清楚、需判连通时 Kruskal 更顺手。 Floyd vs Dijkstran 小且问任意两点用 Floyd；非负权单源用 Dijkstra。 关键路径DAG 上拓扑序做最长路；最早/最迟时间差为 0 是关键活动。 递归树题sys.setrecursionlimit(10**6)，链很长时仍优先迭代。
