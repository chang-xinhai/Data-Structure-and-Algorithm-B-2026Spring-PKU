G:随机数生成器

描述

你将实现一个简易的随机数生成器 my_rand()。不同于标准库中的 rand() 函数，my_rand() 函数将根据你的实现产生一系列随机数。为了生成随机数序列，你需要使用线性同余方法（Linear Congruential Generator, LCG）的简化版。LCG 是一种产生伪随机数的算法，其表达式如下：

X_{n+1} = (a * X_n + c) % m

其中，X 是随机数序列，n 是序列中的位置，a、c 和 m 是算法的参数。为简化问题，我们固定 a=1103515245，c=12345，m=2^31。

你的任务是完成 my_rand() 函数，使其能够在每次被调用时返回序列中的下一个随机数。

此外，你需要实现 my_srand(unsigned int seed)，它将用于设置随机数生成的起始点（即 X_0）。

输入
输入仅一行，包含两个整数，分别是 seed 和 n。seed 是随机数生成的初始种子，n 是需要生成的随机数的数量。
输出
输出 n 个用空格分隔的随机数，这些随机数是通过你实现的 my_rand() 函数生成的。
样例输入
12345 5
样例输出
1406932606 654583775 1449466924 229283573 1109335178
提示
对于所有评测用例，0 <= seed < 2^31，1 <= n <= 10000。

初次调用 my_rand() 之前，应该先调用 my_srand(seed) 来设置初始种子。
请考虑如何在全局范围内保存和更新随机数生成的当前状态。
