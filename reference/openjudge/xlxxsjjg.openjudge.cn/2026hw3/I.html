描述

数学课算多项式好麻烦啊，不如写一个程序，用科技改变生活。

使用单链表存储一个多项式，设计多项式加法、乘法及显示多项式的算法。

输入
两行，每行为一串整数，表示一个多项式，按多项式的指数降序输入，一个多项式的输入用0 0表示结束。多项式3x5-7x+6用一个整数序列表示为：3 5 －7 1 6 0 0 0，即第一个数是系数，第二个数是指数。保证输入多项式项的指数<=100。
输出
两行
第一行为多项式和
第二行为多项的积
输出形式形如3x^5-7x+6
样例输入
3 5 -7 1 6 0 0 0
-4 5 2 2 7 1 2 0 0 0
样例输出
-x^5+2x^2+8
-12x^10+6x^7+49x^6-18x^5-14x^3-37x^2+28x+12
提示
请大家注意各种边界情况（如x、-x、1、0等）
