描述

在现代高性能计算架构中，你负责管理一个包含 n 个专用计算节点的本地集群。为了处理突发的计算任务，你还可以接入一个容量无限但按量计费的公用计算云。

资源限制

  1. 专用节点： 集群中共有 n 个专用节点，编号为 1, 2, ..., n。

  2. 独占性： 每个节点只能处理特定类型的任务。具体来说，第 i 个节点只能执行第 i 类任务。

  3. 硬件容量： 每个节点都有其物理内存或吞吐量限制。你将得到一个长度为 n 的序列 r1, r2, ..., rn，代表第 i 个节点最多只能处理 ri 个任务。

弹性资源

  • 公用云节点： 编号为 n+1 的节点是公用计算云。它可以接受任何种类的任务，且容量几乎无限。

  • 计费模式： 专用节点的使用是免费的，但公用云是按需收费的。每向公用云提交一个任务，平台会向你收取 c 的资源占用费。

某一天，你的系统中堆积了大量待处理任务。经过分类统计，你得到了一个长度为 n 的序列 a1, a2, ..., an，代表第 i 类任务共有 ai 个。

你需要通过合理的任务分配，在保证所有任务都被执行的前提下，计算出最小的总支出费用是多少。

输入
共三行。
第一行： 两个整数 n, c，分别代表任务的种类数和公用云处理单个任务的费用。
第二行： n 个整数 r_1, r_2, ..., r_n，代表各专用节点的任务处理容量。
第三行： n 个整数 a_1, a_2, ..., a_n，代表每一类待处理任务的实际数量。
输出
一行一个整数，代表完成所有任务的最小化费用。
样例输入
2 7
4 3
7 9
样例输出
63
提示
【样例解释】需要有3个1类任务和6个2类任务需要投放到公用云，总费用为7×(3+6)=63.
【数据范围】所有输入数据均为[0, 1000000]之间的整数。
