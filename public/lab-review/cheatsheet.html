A4 / 单页打印

0. I/O 与复杂度

  • read()：多行、空格密集、读到 EOF。
  • splitlines()：保留行结构，适合句子反转。
  • O(n^2)：n≈5000 勉强；n≈1e5 不行。
  • 多组数据先看：第一行 T / EOF / 哨兵。
import sys
it = iter(sys.stdin.read().split())
n = int(next(it))
a = [int(next(it)) for _ in range(n)]

1. 栈 / 队列

  • 表达式、括号、语法检查：优先想栈。
  • BFS 队列：入队时立刻标记 visited。
from collections import deque
q = deque([start])
vis = {start}
while q:
    u = q.popleft()
    for v in nxt(u):
        if v not in vis:
            vis.add(v); q.append(v)

2. 排序 key

  • 多关键字：把规则写成 tuple。
  • 降序用负号，字符串默认字典序。
a.sort(key=lambda x: (-x.score, x.name))
# 奇数在前；奇数降序，偶数升序
a.sort(key=lambda x: (x % 2 == 0, -x if x % 2 else x))

4. 二叉树

  • 层序：队列保存 (node, depth)。
  • 重建：后序最后一个 / 前序第一个是根。
def depth(u):
    if u == 0: return 0
    return 1 + max(depth(left[u]), depth(right[u]))

5. 并查集

fa = list(range(n + 1))
def find(x):
    while fa[x] != x:
        fa[x] = fa[fa[x]]
        x = fa[x]
    return x
def union(a,b):
    fa[find(a)] = find(b)

6. DP 识别

递推：当前只依赖前几项背包：选/不选 + 容量区间：先算短区间树形：答案在子树合并 
# 01 背包：容量倒序
for w, val in items:
    for c in range(C, w - 1, -1):
        dp[c] = max(dp[c], dp[c - w] + val)

# 最大子段和
best = cur = a[0]
for x in a[1:]:
    cur = max(x, cur + x)
    best = max(best, cur)

7. 传递闭包

  • “能推出 A 比 B 高/先于/可达”：Floyd 布尔版。
for k in range(n):
  for i in range(n):
    if reach[i][k]:
      for j in range(n):
        reach[i][j] |= reach[k][j]

8. Dijkstra

import heapq
pq = [(0, s)]; dist[s] = 0
while pq:
    d, u = heapq.heappop(pq)
    if d != dist[u]: continue
    for v, w in g[u]:
        if d + w < dist[v]:
            dist[v] = d + w
            heapq.heappush(pq, (dist[v], v))

9. 考场 Checklist

  • 先做会写题；15 分钟没进展换题。
