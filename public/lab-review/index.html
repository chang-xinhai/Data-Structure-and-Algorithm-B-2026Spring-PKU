思考：为什么 read().split() 会把“每行一句话”的结构破坏掉？

知识点

  • input() 适合结构清楚、行数固定的小输入。
  • sys.stdin.read().split() 适合纯 token 流，例如全是整数。
  • splitlines() 保留行结构，适合“每行一句话”“每行一个记录”。
  • 哨兵输入要先判断结束值，再决定是否加入答案。
  • 输出建议先组装列表，再用 join 控制空格。

数学 / 不变量

输入处理的不变量是：题面定义的记录边界必须在程序中保留。若第 \(i\) 行是一条记录，可记为 \(R_i=\text{line}_i\)，程序不能把所有 token 混成 \(T=\bigcup_i R_i\)。

哨兵序列中，若结束标记为 \(0\)，有效序列是第一次出现 \(0\) 之前的所有元素。

例题迁移

  • 句子反转：按行读，每行内部 split。
  • 数字串倒序：纯数字 token 流，遇到 \(0\) 停止。
  • 多组矩阵题：先读 \(T\)，每组按固定行列读取。
  • 图题边表：通常是 token 流，适合统一读入。

知识点

  • 扫描时维护“到当前位置为止”的摘要信息。

  • 排序 key 是线性扫描后的结构化比较。

数学 / 不变量

最大子段和维护 \(cur_i=\max(a_i,cur_{i-1}+a_i)\)，其中 \(cur_i\) 表示必须以 \(i\) 结尾的最大和，答案为 \(\max_i cur_i\)。

云服务的单项额外费用为 \(\max(0,a_i-r_i)\cdot c\)，总费用为 \(c\sum_i\max(0,a_i-r_i)\)。

例题迁移

  • 云服务：逐类计算超出专用节点容量的任务数。
  • 喝喝喝：找第一个和最后一个 \(1\)，答案是区间长度。
  • 最大子段和：线性 DP。
  • 奇偶权值排序：把规则写入排序 key。
# 云服务：差额累加
capacity = [3, 2, 5]

cost_per_task = 7
extra = sum(max(0, a - r) for a, r in zip(demand, capacity))
print(extra * cost_per_task)

arr = [-2, 3, -1, 5, -4]

思考：后缀表达式和复杂度解析为什么都可以用栈？

知识点

  • 栈用于维护“已经开始但尚未结束”的结构。
  • 后缀表达式：数字入栈，运算符弹出两个操作数。
  • 括号匹配：左括号入栈，右括号检查栈顶。
  • 模拟器题要同时维护多个状态，例如变量集合、当前深度、错误标记。
  • 语法错误通常优先于运行结果。

数学 / 不变量

扫描到位置 \(i\) 时，栈中从底到顶保存所有未闭合结构；栈顶就是最近需要匹配的对象。若所有前缀都合法，任何时刻栈深度都不应为负。

例题迁移

  • 后缀表达式：求值栈。
  • D++：循环层栈 + 活跃变量集合。
  • 括号匹配：括号类型栈。
  • 队列 pk：虽然题名有队列，也要判断是否真的需要栈/队列模拟。
# 后缀表达式：3 4 + 5 * = 35
tokens = ['3', '4', '+', '5', '*']
stack = []
for token in tokens:
    if token.isdigit():
        stack.append(int(token))
    else:
        b = stack.pop()
        a = stack.pop()
        if token == '+': stack.append(a + b)
        elif token == '-': stack.append(a - b)
        elif token == '*': stack.append(a * b)
        elif token == '/': stack.append(int(a / b))
print(stack[-1])

思考：树题的难点是算法本身，还是把结构存对？

知识点

  • 编号树可用 \(left[u],right[u]\) 或邻接表存储。
  • 层相关问题优先 BFS，例如层序遍历、每层结点数。
  • 子树相关问题优先 DFS，例如深度、子树规模、树形 DP。
  • 中序 + 前序或中序 + 后序可以唯一重建普通二叉树。
  • 树编码解析要维护当前位置指针。

数学 / 不变量

若根在中序序列中的位置为 \(k\)，左子树规模为 \(k-l\)，右子树规模为 \(r-k\)。前序第一个是根，后序最后一个是根。

深度递推：\(depth(u)=1+\max(depth(left_u),depth(right_u))\)。

例题迁移

  • 最多结点层：队列保存 \((node,depth)\)。
  • P4913：递归或迭代求深度。
  • P1030：由中序与后序输出前序。
  • 二叉树作业：树编码解析 + DP。
from collections import deque

children = {
    1: (2, 3),
    2: (4, 0),
    3: (0, 0),
    4: (0, 0),
}
q = deque([(1, 0)])
cnt = []
while q:
    u, d = q.popleft()
    if d == len(cnt):
        cnt.append(0)
    cnt[d] += 1
    for v in children[u]:
        if v:
            q.append((v, d + 1))
print(cnt)
print(max(range(len(cnt)), key=lambda i: cnt[i]))

信号：矩阵四方向、连通块、最短步数、能否到达、从某个点扩散。

思考：为什么 BFS 的访问标记通常要在入队时完成？

知识点

  • BFS 适合无权最短路；DFS 适合遍历、连通块、回溯枚举。
  • 矩阵常用四方向：上、下、左、右。
  • 状态不一定只是坐标，也可能是 \((x,y,key,step)\)。
  • Flood Fill 中“改色”本身可以作为访问标记。
  • 路径恢复需要保存前驱。

数学 / 不变量

无权图 BFS 队列按距离非降序弹出。第一次到达状态 \(v\) 时，得到的就是最短距离 \(dist[v]\)。入队即标记可以保证每个状态最多入队一次。

例题迁移

  • 图像渲染：从起点扩展同色连通块。
  • 迷宫问题：BFS 求最短路径或恢复路径。
  • Pots：状态是两个水壶的水量。
  • 无尽迷宫：周期网格上的可达性判定。
from collections import deque

grid = [
    'S..',
    '.#.',
    '..T',
]
n, m = 3, 3
sx, sy = 0, 0
dist = [[-1] * m for _ in range(n)]
q = deque([(sx, sy)])
dist[sx][sy] = 0
while q:
    x, y = q.popleft()
    for dx, dy in ((1,0),(-1,0),(0,1),(0,-1)):
        nx, ny = x + dx, y + dy
        if 0 <= nx < n and 0 <= ny < m and grid[nx][ny] != '#':
            if dist[nx][ny] == -1:
                dist[nx][ny] = dist[x][y] + 1
                q.append((nx, ny))
print(dist[2][2])

思考：什么时候一个局部最优选择不够，需要保留状态？

知识点

  • 先定义状态，再写转移，最后决定循环顺序。
  • 递推题通常只依赖前若干项。
  • 01 背包容量倒序，完全背包容量正序。
  • 不可达状态要与值为 \(0\) 的合法状态区分。
  • 状态压缩前要确认转移依赖方向。

数学 / 不变量

01 背包中，\(dp[c]\) 表示容量不超过 \(c\) 时的最大价值。对物品 \((w,v)\)，转移为 \(dp[c]=\max(dp[c],dp[c-w]+v)\)。倒序枚举保证每件物品只用一次。

例题迁移

  • Fibonacci：预处理多询问。
  • 最大子段和：一维状态压缩。
  • 采药：01 背包。
  • 数字三角形：从上方或下方递推。
# 01 背包示例
capacity = 5
items = [(2, 3), (3, 4), (4, 5)]
dp = [0] * (capacity + 1)
for weight, value in items:
    for c in range(capacity, weight - 1, -1):
        dp[c] = max(dp[c], dp[c - weight] + value)
print(dp[capacity])

fib = [0, 1]
for _ in range(2, 8):
    fib.append(fib[-1] + fib[-2])

信号：模式串、重复出现、整体平移、前后缀重叠、子串快速比较。

思考：“整体升高或降低都算匹配”为什么要转成差分？

知识点

  • KMP 用前缀函数避免重复比较。
  • 若允许整体加同一常数，应比较相邻差分。
  • 字符串哈希可快速比较片段，但有冲突风险。
  • 重叠出现次数与最长公共前后缀有关。
  • 模式串长度为 \(1\) 时常需单独处理。

数学 / 不变量

两个长度为 \(w\) 的序列允许整体平移匹配，当且仅当差分序列相等：\(a_i-b_i=C \iff a_{i+1}-a_i=b_{i+1}-b_i\)。KMP 中 \(\pi[i]\) 表示前缀与后缀的最长相等长度。

例题迁移

  • 索菲的血瓶：差分后做模式匹配。
  • KMP 模板：查找所有出现位置。
  • 古代密码：排序或计数比较字符结构。
  • 猴子当文豪：前后缀重叠影响最大出现次数。
def prefix_function(s):
    pi = [0] * len(s)
    for i in range(1, len(s)):
        j = pi[i - 1]
        while j and s[i] != s[j]:
            j = pi[j - 1]
        if s[i] == s[j]:
            j += 1
        pi[i] = j
    return pi

思考：为什么“成绩排序”不是直接排序，而是关系推断？

知识点

  • 把“高于/先于/可推出”建成有向边。
  • 传递闭包判断任意两点关系是否可推出。

数学 / 不变量

Floyd 后，\(reach[i][j]\) 表示存在从 \(i\) 到 \(j\) 的有向路径。排名可确定条件为 \(\sum_{j\ne i}[reach[i][j]\lor reach[j][i]]=n-1\)。

例题迁移

  • 成绩排序：由回答推断名次。
  • Cow Contest：牛之间胜负关系。
  • 课程先修关系：可达性表示先后约束。
  • 若有环，需结合题意判断是否矛盾或等价。
n = 4
relations = [(0, 1), (1, 2), (2, 3)]  # 0 高于 1，高于关系可传递
reach = [[False] * n for _ in range(n)]
for a, b in relations:
    reach[a][b] = True

for k in range(n):
    for i in range(n):
        if reach[i][k]:
            for j in range(n):
                reach[i][j] |= reach[k][j]

ans = 0
for i in range(n):
    known = sum(reach[i][j] or reach[j][i] for j in range(n) if i != j)
    ans += known == n - 1
print(ans)

Case 04

这类题最适合强调代码顺序：先记录旧颜色，再判断是否无需修改，然后 BFS/DFS，最后输出矩阵。\(old = color\) 是很多人会漏掉的边界。

  • 题面信号：从一个点开始，修改相邻同色区域。
  • 关键动作：四方向扩展，入队时立刻改色/标记。
  • 常见坑：修改原图后忘记旧颜色，导致判断条件变化。
from collections import deque

def fill(image, sr, sc, color):
    n, m = len(image), len(image[0])
    old = image[sr][sc]
    if old == color:
        return image
    q = deque([(sr, sc)])
    image[sr][sc] = color
    while q:
        x, y = q.popleft()
        for dx, dy in ((1,0),(-1,0),(0,1),(0,-1)):
            nx, ny = x + dx, y + dy
            if 0 <= nx < n and 0 <= ny < m and image[nx][ny] == old:
                image[nx][ny] = color
                q.append((nx, ny))
    return image

def prefix_function(s):
    pi = [0] * len(s)
    for i in range(1, len(s)):
        j = pi[i - 1]
        while j and s[i] != s[j]:
            j = pi[j - 1]
        if s[i] == s[j]:
            j += 1
        pi[i] = j
    return pi
