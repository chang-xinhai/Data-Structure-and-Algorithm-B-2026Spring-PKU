J:科学计数法

描述

注意看，这个男人叫小帅。他今天上了D老师的数算课，灵光一闪，决定自己写一个科学计数法的简单计算程序。该程序能实现两个数的加、减、乘、除运算，并以科学计数法的形式返回结果。

输入
程序输入分为两行：第一行以科学计数法的形式输入两个数字（如“1.5e6 2e7”）,第二行输入算子类型('+', '-', '*', '/')。
输出
以科学计数法形式输出计算结果，具体格式见样例和提示。输出结果保留两位小数。
样例输入
Case 1:
3e5 4.2e3
*

Case 2:
6e1 -1e2
+

Case 3:
3e0 9e1
/

Case 4:
1e3 4e3
-
样例输出
Case 1:
1.26e9

Case 2:
-4.00e1

Case 3:
3.33e-2

Case 4:
-3.00e3
提示
输入长度小于20字符。
为减少表达难度，输出格式统一为（<Num>e<Index>）的形式，Index=0的情况仍不省略。
不会出现Error数据（比如0做除数，未定义的算子等），但在以后的情况中需要谨慎考虑非法输入。
