描述

Y同学写代码时永远开着很多浏览器标签页，这些标签页从左到右排成一条线性结构，系统始终有一个当前聚焦标签页。
喜欢用快捷键的他留下了很多操作日志，现在需要你模拟整个标签页管理过程。

初始时共有 N 个标签页，编号依次为 1,2,...,N，从左到右排列。当前聚焦的标签页编号为 S。接下来有 Q 条操作，每条操作属于以下六种之一：

A：将当前标签页移动到左侧相邻标签页。若当前已经在最左端，则保持不变。
B：将当前标签页移动到右侧相邻标签页。若当前已经在最右端，则保持不变。
L id：在当前标签页的左侧新建一个编号为 id 的标签页，并立刻将其设为当前标签页。
R id：在当前标签页的右侧新建一个编号为 id 的标签页，并立刻将其设为当前标签页。
D：关闭当前标签页。关闭后，若右侧仍有标签页，则当前标签页变为右侧相邻标签页；否则变为左侧相邻标签页。保证执行该操作时至少有两个标签页。
J id：直接跳转到编号为 id 的标签页，并将其设为当前标签页。保证该标签页当前存在。

所有新建标签页的编号两两不同，且不会与初始编号 1..N 重复。

输入
第一行输入三个整数 N, Q, S，分别表示初始标签页数量、操作条数、初始当前标签页编号。
接下来 Q 行，每行表示一条操作，格式如下之一：
A
B
L id
R id
D
J id
输出
共输出三行：
  • 第一行输出一个整数，表示最终仍打开的标签页数量。
  • 第二行按从左到右顺序输出所有仍存在的标签页编号，整数之间用空格分隔。
  • 第三行输出最终当前聚焦的标签页编号。
样例输入
4 8 2
R 5
A
L 6
B
D
J 4
R 7
A
样例输出
6
1 6 5 3 4 7
4
