## 🔧 本地构建

</div>

```bash
# 安装依赖
npm install

# 本地预览（开发）
npm run preview

# 构建生产文件（输出至 public/）
npm run build
```

> [!NOTE]\
> `public/` 目录即为 GitHub Pages 部署目录，`npm run build` 会将所有资源输出到该目录。
