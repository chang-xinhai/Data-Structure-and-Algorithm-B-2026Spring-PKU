D:结点数量最多的层所在深度

  • 查看
  • 提交
  • 统计
  • 提问
总时间限制:
5000ms
内存限制:
65535kB
描述

给定一棵二叉树，请你找出该二叉树中结点最多的那一层 ，并输出这一层的深度。
如果有多层同时拥有相同的最多结点数，则输出最先出现的那一层 （即深度最小的那一层）。

输入
第一行为一个整数 N，代表测试用例的数量；随后为N组数据，每组数据中：
第一行是一个整数 n，表示二叉树的结点个数。（1 ≤ n ≤ 10）
接下来有 n 行，每行包含两个整数，分别表示当前节点的左孩子编号 和右孩子编号 。
若某子节点为空，则用 0 表示。
根节点编号为 1。
输出
输出一个整数，表示节点最多的那一层的深度（从0开始计数）
样例输入
2
3
2 3
0 0
0 0
5
2 3
4 0
0 5
0 0
0 0
样例输出
1
1
提示
对于所有的测试样例，节点数量不超过10000.
