### 板块 1：数据结构基础（5 min）

#### 1.1 逻辑结构 vs 存储结构

> **插图**：见附录 [图 1](#图-1-逻辑结构-vs-存储结构对照图)

**核心知识点：**

- **逻辑结构**（数据元素之间的逻辑关系）：
  - 集合结构 — 无前驱无后继
  - 线性结构 — 至多一个前驱、一个后继（$\subseteq$ 树形结构）
  - 树形结构 — 至多一个前驱、多个后继（$\subseteq$ 图结构）
  - 图结构 — 多个前驱、多个后继

- **存储结构**（数据在计算机中的存储方式）：
  - 顺序存储 — 物理相邻，逻辑关系由存储单元的邻接关系体现
  - 链式存储 — 通过指针字段表示逻辑关系
  - 索引存储 — 建立附加索引表标识结点地址
  - 散列存储 — 根据关键字直接计算存储地址

- **三要素**：逻辑结构 + 存储结构 + 运算（增删改查、遍历、排序）

> **关键区分**：线性表 / 栈 / 队列 / 二叉树是**逻辑结构**概念；链表 / 顺序表是**存储结构**概念。
> 真题示例：2023 二(5) — "下列哪个概念属于存储结构？→ 链表"

#### 1.2 算法评价

**四要素**：正确性、可读性、健壮性、效率（时间 + 空间）

**时间复杂度**：关注 $O(1) < O(\log n) < O(n) < O(n\log n) < O(n^2) < O(n^3) < O(2^n)$

**典型坑**：
- 数据元素是数据的基本单位；数据**项**才是最小单位（不可分割）→ 2019 一(10)
- 时间复杂度数量级化简：$(n^3+n^2\log_2 n+14n)/n^2 \to O(n)$ → 2019 三(2)

> 真题示例：2019 三(1)(2)(9)(10)；2021 二(9)(10)

### 板块 2：线性结构（8 min）

> **插图**：见附录 [图 2](#图-2-线性结构全家福栈队列串链表)

#### 2.1 顺序表 vs 链表

| 维度 | 顺序表 | 单链表 | 双链表 | 带尾指针循环单链表 |
|------|--------|--------|--------|---------------------|
| 随机存取 | $O(1)$ | $O(n)$ | $O(n)$ | $O(n)$ |
| 头部插入 | $O(n)$ | $O(1)$ | $O(1)$ | $O(1)$ |
| 尾部插入 | $O(1)$ | $O(n)$ | $O(1)$ | $O(1)$ |
| 中间插入 | $O(n)$ | $O(n)$ | $O(n)$ | $O(n)$ |
| 删除头部 | $O(n)$ | $O(1)$ | $O(1)$ | $O(1)$ |
| 删除尾部 | $O(1)$ | $O(n)$ | $O(1)$ | $O(n)$ |
| 存储密度 | 高 | 低 | 低 | 低 |

**选择原则**：
- 频繁存取 + 少插入删除 → 顺序表
- 频繁插入删除 → 链表（头部用单链表，两端用双链表，尾部 + 头部用带尾指针循环单链表）

> 真题示例：2021 三(1)(2)(3)；2023 三(1)

#### 2.2 栈（Stack）

- **特点**：LIFO，插入删除限定在表的一端（栈顶）
- **存储**：顺序栈（top 指针）、链栈（无头结点，新结点插在头部）
- **经典应用**：
  - 出栈序列合法性判断（Catalan 数 $C_n = \frac{1}{n+1}\binom{2n}{n}$）
  - 中缀表达式 → 后缀表达式
  - 后缀表达式求值
  - 括号匹配、递归调用栈

**出栈序列判断方法**：对任意元素，其后所有**比它小**的元素必须**逆序**出现。

> 真题示例：2019 二(9)、四(3)；2022 一(7)、二(7)(8)(9)；2023 二(1)(14)

#### 2.3 队列（Queue）

- **特点**：FIFO，一端插入（队尾）、一端删除（队头）
- **循环队列**：
  - 元素个数：$(rear - front + n) \bmod n$
  - 判空：$front = rear$（或增设标志位）
  - 判满：$(rear + 1) \bmod n = front$
  - **假溢出**：rear 到数组末尾但前面有空位 → 用循环队列解决

> 真题示例：2023 二(10)；2022 四(6)

#### 2.4 串（String）

- **基本操作**：求串长、串比较、串连接、求子串、子串定位
- **模式匹配**：
  - 朴素匹配：$O(nm)$
  - KMP 匹配：$O(n+m)$
  - 前缀函数 $\pi[i]$ = `s[0..i]` 的最长相等真前后缀长度
  - **最短周期**：$p = n - \pi[n-1]$（即使 $p \nmid n$ 也成立，已知 2025 期中真题）

> 真题示例：2021 二(3) — 前缀编码判断；2022 二(5) — 字符串相等条件

### 板块 3：树与二叉树（8 min）

> **插图**：见附录 [图 3](#图-3-二叉树核心性质与遍历)

#### 3.1 二叉树性质（必背）

1. 第 $i$ 层最多 $2^{i-1}$ 个结点（$i \ge 1$）；深度 $k$ 的二叉树最多 $2^k - 1$ 个结点
2. **$n_0 = n_2 + 1$**（叶子数 = 度为 2 的结点数 + 1）
3. $n$ 个结点的**二叉链表**：
   - 指针域总数 $= 2n$
   - 非空指针 $= n-1$（每个结点一条入边，根无入边）
   - 空指针 $= n+1$（$2n - (n-1) = n+1$）
4. 完全二叉树：深度 $k = \lfloor \log_2 n \rfloor + 1$
5. 编号关系（1-indexed）：左孩子 $2i$，右孩子 $2i+1$，双亲 $\lfloor i/2 \rfloor$

#### 3.2 遍历

| 遍历方式 | 顺序 | 应用 |
|----------|------|------|
| 先序 | 根→左→右 | 复制树、前缀表达式 |
| 中序 | 左→根→右 | **BST 的中序是有序序列** |
| 后序 | 左→右→根 | 删除树、后缀表达式 |
| 层序 | 按层从上到下 | BFS、求宽度/深度 |

- **重建**：已知中序 + 先序（或后序）可以唯一确定二叉树
- **不能单独由先序+后序确定**（除非是完全二叉树或满二叉树）→ 2023 二(4)

> 真题示例：2019 二(2)(3)(4)；2021 二(4)；2022 二(3)；2023 三(4)

#### 3.3 树 ↔ 森林 ↔ 二叉树 转换

> **插图**：见附录 [图 4](#图-4-树森林二叉树转换规则)

**核心规则：**

- **树 → 二叉树**：左孩子右兄弟（每个结点左指针指向第一个孩子，右指针指向下一个兄弟）
- **森林 → 二叉树**：每棵树分别转为二叉树，再用右指针串联
- **二叉树 → 森林/树**：逆向操作

**关键结论：**
- 森林 F 对应二叉树 B，B 的根无右子树当且仅当 F 只有一棵树
- 森林 F 中第一棵树的结点数 = B 根的左子树结点数 + 1
- 森林 F 中非终端结点数为 n，则对应的二叉树 B 中右指针域为空的结点数 = n + 1

> 真题示例：2019 二(2)、三(3)；2021 二(1)；2022 二(1)(2)、三(7)；2023 三(9)

#### 3.4 二叉排序树（BST）

- **定义**：左子树所有结点 < 根 < 右子树所有结点
- **性质**：中序序列有序
- **删除**：左子树最大者（或右子树最小者）替代被删结点
- **注意**：先序序列不一定有序 → 2021 一(4) 为错

> 真题示例：2019 一(7)；2022 三(2)；2023 二(8)、四(2)

#### 3.5 哈夫曼树（Huffman）

- $n$ 个叶子结点 → $2n-1$ 个总结点
- 构造：选权值最小的两棵树合并，重复
- **WPL** = 所有叶子结点的 权值 × 路径长度 之和
- 哈夫曼编码是**前缀编码**（任何一个编码不是另一个编码的前缀）
- 应用：数据压缩

> 真题示例：2022 二(3)、三(1)、四(2)；2023 三(5)

#### 3.6 堆（Heap）

- **结构性质**：完全二叉树
- **堆序性质**：大根堆（父 ≥ 子）/ 小根堆（父 ≤ 子）
- **建堆**：从最后一个非叶结点 `⌊n/2⌋` 向前调整，复杂度 $O(n)$
- **调整**（sift-down）：$O(\log n)$
- **堆排序**：建堆 $O(n)$ + $n-1$ 次调整 $O(n\log n)$ = $O(n\log n)$，不稳定

> 真题示例：2019 三(8)；2023 三(6)

### 板块 4：图（5 min）

> **插图**：见附录 [图 5](#图-5-图算法全景图)

#### 4.1 存储结构

| 存储方式 | 空间 | 适用场景 |
|----------|------|----------|
| 邻接矩阵 | $O(n^2)$ | 稠密图 |
| 邻接表 | $O(n+e)$ | 稀疏图 |

- 邻接表中，**有向图**有 $e$ 个边结点，**无向图**有 $2e$ 个边结点 → 2019 三(6)

#### 4.2 遍历

- **DFS**：递归 / 栈
- **BFS**：队列
- 时间复杂度（邻接表）：$O(n+e)$
- 时间复杂度（邻接矩阵）：$O(n^2)$
- DFS 和 BFS **同时适用于有向图和无向图** → 2023 二(9) 为错
- **无向图的连通分量**：调用 DFS/BFS 的次数 → 2023 五(4)

#### 4.3 最小生成树（MST）

- **Prim**：$O(n^2)$ — 选点，适合稠密图（邻接矩阵）
- **Kruskal**：$O(e\log e)$ — 选边，适合稀疏图
- 若所有边权值互不相同，MST 唯一 → 2023 二(10)

#### 4.4 最短路径

- **Dijkstra**：单源最短路径，要求非负权边
- **Floyd**：多源最短路径，$O(n^3)$，可处理负权（无负环）
  - Floyd 的核心递推：$d[i][j] = \min(d[i][j], d[i][k] + d[k][j])$

#### 4.5 拓扑排序

- **适用范围**：有向无环图（DAG）
- **Kahn 算法**：计算入度，BFS 输出入度为 0 的顶点
- 拓扑序列**可能不唯一** → 2021 一(3)

#### 4.6 图的基本性质

- $n$ 个顶点无向连通图最少 $n-1$ 条边（树）
- $n$ 个顶点非连通无向图，边数为 $e$ 时，最少顶点数 = 完全图 $K_k$ 的最小 $k$ 满足条件
- 若 $e > n-1$，无向图**不一定**连通 → 2021 一(5)

> 真题示例：2023 二(11) — "21 条边的非连通无向图，至少几个顶点？→ 8"

### 板块 5：排序（4 min）

> **插图**：见附录 [图 6](#图-6-排序算法全览对比图)

#### 5.1 排序算法速查表

| 算法 | 最好时间 | 平均时间 | 最坏时间 | 空间 | 稳定性 |
|------|----------|----------|----------|------|--------|
| 直接插入排序 | $O(n)$ | $O(n^2)$ | $O(n^2)$ | $O(1)$ | ✓ 稳定 |
| 二分插入排序 | $O(n\log n)$ | $O(n^2)$ | $O(n^2)$ | $O(1)$ | ✓ 稳定 |
| 冒泡排序 | $O(n)$ | $O(n^2)$ | $O(n^2)$ | $O(1)$ | ✓ 稳定 |
| 简单选择排序 | $O(n^2)$ | $O(n^2)$ | $O(n^2)$ | $O(1)$ | ✗ 不稳定 |
| 希尔排序（Shell） | — | $O(n^{1.3})$ | — | $O(1)$ | ✗ 不稳定 |
| 快速排序 | $O(n\log n)$ | $O(n\log n)$ | $O(n^2)$ | $O(\log n)$ | ✗ 不稳定 |
| 归并排序 | $O(n\log n)$ | $O(n\log n)$ | $O(n\log n)$ | $O(n)$ | ✓ 稳定 |
| 堆排序 | $O(n\log n)$ | $O(n\log n)$ | $O(n\log n)$ | $O(1)$ | ✗ 不稳定 |
| 基数排序 | — | $O(d(n+r))$ | — | $O(n+r)$ | ✓ 稳定 |

#### 5.2 高频易错点

1. **简单选择排序的比较次数与初始顺序无关**（总是 $n(n-1)/2$）→ 2019 一(6)
2. **快速排序不是稳定排序** → 2019 一(8)
3. 快速排序在**正序时退化为 $O(n^2)$**（每次 pivot 到一端）
4. 直接插入排序在**正序时只需 $n-1$ 次比较** → 2022 一(1)
5. **堆排序不稳定**，归并排序稳定
6. 希尔排序的**增量序列**影响效率，最后一趟必须是增量为 1 的直接插入

#### 5.3 排序算法选择指南

- $n$ 小 + 基本有序 → 直接插入
- $n$ 大 + 要求稳定 → 归并
- $n$ 大 + 内存受限 → 堆排序
- $n$ 大 + 平均最快 → 快速排序
- 关键字位数少 → 基数排序

#### 算法填空 — 重点精讲（15 min）

**题 1：带尾指针的循环单链表**（6 分）

```
(1) nd.next = self.tail.next    # 新结点的 next 指向当前第一个结点
(2) self.tail.next == self.tail # 只有一个结点（自己指向自己）
(3) ptr.next != self.tail       # 未到达最后一个结点的前一个
(4) self.tail = ptr             # 删除后更新尾指针
(5) ptr != self.tail.next       # 未回到第一个结点
```

**题 2：二叉树宽度**（6 分）

```
(1) traversal(root.left, level + 1)
(2) traversal(root.right, level + 1)
(3) nodes[L].data = L           # 或保存其他信息
(4) nodes[R].data = R
(5) nodes[i].left or nodes[i].right # 查找根结点（没有父结点的那个）
```

**题 3：Prim 最小生成树**（7 分）

```
(1) doneNum < n
(2) dist[i] < minDist
(3) used[x] = True
(4) (x, prev[x]) 或 (prev[x], x)
(5) G[x][v] is not None and G[x][v] < dist[v]
(6) prev[v] = x
```

**题 4：连通分量计数**（7 分）

```
(1) not visited[i]
(2) dfs(i, visited, graph, n)
(3) graph[u].append(v)
(4) graph[v].append(u)
(5) not visited[i]
(6) dfs(i, visited, graph, n)
```

### 第 2 轮：2019–2020 年真题（20 min）

**选择这份的原因**：题型结构最经典（判断 20 + 选择 30 + 填空 20 + 简答 30），**简答题**是重点。

#### 重点简答题讲解

**三(1) 算法评价四要素**：正确性、可读性、健壮性、效率（这题每年都可能换个形式出现）

**三(3) 广义表 A(C, D(E, F, G), H(I, J))**：
- 结点数 = 9（A, C, D, E, F, G, H, I, J）
- 深度 = 3（A → D → E）或归纳法：最外层深度 1，子表深度 +1
- 度 = 3（A 有 3 个子表：C, D(…), H(…)）

**三(4) 后缀表达式求值**：
- `9 2 3 + - 10 2 / -` = `9 - (2+3) - (10/2)` = `9 - 5 - 5` = `-1`
- 中缀 `(3+4X)-2Y/3` → 后缀 `3 4 X × + 2 Y × 3 / -`

**三(5) $n$ 个结点二叉链表的指针域**：$2n$ 总、$n-1$ 非空、$n+1$ 空

**三(7) B-tree 根分裂**：新树比原树**增高 1**

**四(3) 不带头结点的单链表插入**（算法设计）：

```
def insert_before_k(L, k, x):
    if L is None:  return Node(x)
    if L.data == k:                       # 头结点就是 k
        nd = Node(x); nd.next = L; return nd
    prev, curr = None, L
    while curr and curr.data != k:
        prev, curr = curr, curr.next
    nd = Node(x)
    if curr:                              # 找到 k
        nd.next = curr; prev.next = nd
    else:                                 # 未找到 k，插入末尾
        prev.next = nd
    return L
```
