描述

最近，一款找牛小游戏吸引了不少大学生。这款找牛游戏的玩法很简单：

给定一个大小为 N×N 的网格矩阵，矩阵中的每个方格被涂上了颜色。共有 N 种不同的颜色，用整数 1 到 N 标识。每种颜色在矩阵中恰好构成一个四连通块（即同色方格可以通过上下左右相邻的边互相到达）。

你需要在网格中找出恰好 N 头牛的位置（每头牛占据一个方格），且必须同时满足以下所有规则：

  1. 颜色限制：每种颜色所在的连通块内，恰好包含一头牛。

  2. 行列限制：矩阵的每一行、每一列都恰好包含一头牛。

  3. 非相邻限制：任意两头牛不能相邻。此处的相邻指八连通相邻（即两头牛所在的方格不能共享同一条边或同一个顶点）。

为了能够快速通关，你需要编写一个外挂程序，通过算法自动计算出当前关卡中所有牛的准确位置。

输入
第一行包含一个正整数 N，表示网格的大小以及牛的总数。
接下来的 N 行，每行包含 N 个由空格分隔的正整数 A_{ij}，表示第 i 行第 j 列方格的颜色编号。
输出
输出一个 N×N 的矩阵，表示找出牛之后的网格状态。
对于有牛的方格，输出数字 0；对于没有牛的方格，输出该方格原本的颜色编号。相邻数字之间用单个空格隔开。
数据保证存在唯一解。
样例输入
4
1 1 1 2
3 3 1 2
3 3 2 2
3 3 4 2
样例输出
1 0 1 2
3 3 1 0
0 3 2 2
3 3 0 2
提示
【数据范围】1≤N≤14,1≤A_{ij}≤N。
