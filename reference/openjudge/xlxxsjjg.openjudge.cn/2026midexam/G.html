描述

课题组正在训练一个基于深度强化学习的智能体，用于控制一架高海拔长航时无人机在复杂气流环境中的平流层进行数据采集。

我们将无人机飞行的二维环境建模为一个 n×m 的离散状态空间网格。其中，x 轴表示水平位置（从 1 到 m），y 轴表示高度层（从 1 到 n）。

最底层（y=1）是无人机的通信基准层，第 n 行（y=n）是探测上限边界层。

智能体需要从基准层的 (1, 1) 位置起飞，并最终到达目标位置 (m, 1)。无人机的初始垂直速度为 0。

在每个时间步，智能体的状态机和环境交互遵循以下马尔可夫决策过程：

假设当前时间步无人机位于 (x, y)，当前的垂直速度为 v。智能体可以通过策略网络输出一个动作 at ∈ {+1, -1, 0}，即调节垂直加速度：

  • 执行动作后，无人机的瞬时速度更新为 v' = v + at。

  • 随后环境发生状态转移，无人机在下一个时间步将移动到状态坐标 (x + 1, y + v')。

  • 边界截断： 如果计算得出的下一高度层超越了探测上限（即 y + v' > n），受通信限制，无人机必须贴着边界飞行，即状态转移至 (x + 1, n)。

网格空间的每一个状态节点 (x, y) 上，都分布着以下两种环境特征之一：

  • 气流扰动（特征前缀 f）： 具有属性值 w。当无人机转移到该状态节点时，环境会对其施加一个外部扰动，使得无人机当前的速度被强制叠加变为 v' + w（注意：这不影响智能体在下一个时间步继续自主输出 +1, -1, 0 的动作）。

  • 高价值数据（特征前缀 d）： 具有属性值 r。当无人机转移到该状态节点时，智能体将获得 r 点奖励值。

为了确保飞行安全与任务顺利完成，算法引擎中硬编码了以下两个安全约束：

  1. 稳定态重置： 当无人机到达基准层，即处于状态 (x, 1) 时，飞行控制系统会强制将无人机的垂直速度重置为 0（在此状态下，气流扰动失效，下一个时间步的动作空间依然为 {+1, -1, 0}）。

  2. 储能通信瓶颈： 无人机不能在基准层以上的长时脱网环境中待太久。两次返回通信基准层的间隔时间不能超过 k 个时间步。

作为项目负责人，你需要求解出该智能体从 (1,1) 到达 (m, 1) 所能获取的最大累计奖励。

输入
第一行包含三个整数 n, m, k，分别表示状态空间的高度层数、水平位置范围以及最大脱网时长。
第二行到第 n+1 行，每行包含 m 个字符串，第(i+1)行的第j个字符串表示环境中位于(j, n-i+1)状态节点的特征分布情况：首字母为 f，后接一个整数 w，表示该节点存在一个气流扰动器，扰动值为 w。首字母为 d，后接一个整数 r，表示该节点存在一个数据包，奖励值为 r。
输出
一行一个整数，表示智能体能够获得的最大累计奖励。
样例输入
3 3 3
f3 d-1 f-1
d3 d19 f2
d1 f1 d1
样例输出
2
提示
【样例解释】输入样例所描述的空间状态如图所示。
【数据范围】1≤n≤100，1≤m≤1000，1≤k≤10，−20≤w≤20，−1000≤r≤1000。
