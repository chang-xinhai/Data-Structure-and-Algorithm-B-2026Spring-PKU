E:LLM读论文

  • 查看
  • 提交
  • 统计
  • 提问
总时间限制:
10000ms
单个测试点时间限制:
1000ms
内存限制:
131072kB
描述

小A同学最近正在做研究课题调研，为了提高效率，他想让一个大语言模型（LLM）按指定的先后顺序阅读 N 篇学术论文。已知按顺序给出的第 i 篇论文的词元（Token）数量为 Ai。

由于大语言模型的上下文窗口容量有限，单次交互最多只能输入 M 个 Token。为了保证学术理论推导的连贯性，小A必须将连续的若干篇论文合并为一批，在一次交互中喂给大模型。

现要求在保证每次交互输入的论文 Token 总数不超过 M（可以等于 M）的前提下，计算出最少需要与大语言模型进行多少次交互，才能让它按原顺序读完所有的论文。

输入
第 1 行包含两个正整数 N, M，分别表示需要阅读的论文总篇数以及大模型单次交互支持的最大 Token 数量。第 2 行包含 N 个由空格隔开的正整数 A_i，按先后顺序表示每篇论文的 Token 数量。
输出
一个正整数，输出最少需要的交互次数。
样例输入
5 6
4 2 4 5 1
样例输出
3
提示
数据范围限制：N ≤ 10^5，M ≤ 10^9。保证 M 大于或等于单篇论文 Token 数量的最大值（即任何单独的一篇论文都可以在一次交互中被大模型读取），且所有 A_i 之和不超过 10^9。

样例说明：将论文按如下方式划分批次进行交互：
[4] [2 4] [5 1]
第 1 次交互包含第 1 篇论文，总 Token 数为 4；第 2 次交互包含第 2、3 篇论文，总 Token 数为 6；第 3 次交互包含第 4、5 篇论文，总 Token 数为 6。每次交互的 Token 数均满足不超过 M = 6 的条件，并可以证明 3 次是最少的划分次数。
